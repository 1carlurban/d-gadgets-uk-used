D GADGETS UK USED — WEBSITE FILES

Files:
- index.html: complete responsive website; no build tools required.

Preview locally:
1. Extract the ZIP.
2. Double-click index.html to open it in a browser.

Publish with GitHub Pages:
1. Create a public repository named d-gadgets-uk-used.
2. Upload index.html to the repository root and commit.
3. In repository Settings > Pages, select Deploy from a branch.
4. Choose the main branch and /(root), then Save.
5. GitHub will show your published website URL in Settings > Pages.

To update prices:
Open index.html in a text editor and find the `const phones = [` list near the bottom.
Edit product names, storage, and price values (prices are plain numbers in UGX). Use price:null for “Contact for price”.
WhatsApp is set to +256 746 330 991. Business address and email are in the Contact section.

Note: This is a static storefront. It does not process payments or include a password-protected online admin dashboard.
